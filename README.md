# @turystack/nestjs-social-auth

Social OAuth identity resolution for NestJS: Google, Facebook, Microsoft, and Apple.

## Installation

```bash
pnpm add @turystack/nestjs-social-auth
```

### Peer dependencies

The host application provides these:

```bash
pnpm add @nestjs/common @nestjs/core @turystack/nestjs-config reflect-metadata
```

## Documentation

Options, API reference and examples:

**https://tury.dev/libs/nestjs-social-auth**

## Development

```bash
pnpm install
pnpm typecheck
pnpm check
pnpm test
pnpm build
```
